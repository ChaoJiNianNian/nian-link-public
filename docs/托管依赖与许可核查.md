## 新包目录验证

使用 .NET SDK 10.0.402 和显式 NuGet 官方源，在新建的空 packages 目录成功完成 Windows 项目不指定运行时的还原与托管构建，0 警告、0 错误。未禁用 NuGet HTTP 缓存，故不是全新系统或完全无缓存验证。相同隔离条件下，Windows win-x64 运行时依赖还原及 Mac 候选还原分别遇下载超时或连接中断，未完成，不能称这两条从空包目录构建成功；该结果也不单独证明源码有缺陷。

随后针对 osx-arm64 在另一独立源码副本重试：新 packages 目录预先复制本机 27 个完整包，并允许 HTTP 缓存；显式官方源、禁用并行后还原成功，`--no-restore` 托管构建 0 警告、0 错误，25 个依赖内容摘要与该隔离缓存一致。此结果复用了既有缓存，不是全新电脑或 Mac 原生重建。

Windows win-x64 也在另一独立源码副本重试成功：新的隔离 packages 目录预先复制本机 2 个完整包，显式官方源、禁用并行且允许 HTTP 缓存；以非自包含方式完成还原和 `--no-restore` Release 构建，0 警告、0 错误。DisplayBridge 的 4 个输出与复制后的文件哈希一致。该结果不包含完整原生核心或安装包，也不是空白机验证。
