# 年年互联多设备版：安装与首次连接（内部测试）

本说明适用于 Windows 多设备内测版以及 Apple 芯片 Mac 测试端，尚不是正式发布版。让所有电脑连入同一可信局域网；先停止其他键鼠共享，避免冲突。配对文件包含控制凭证，只私下发送给自己的对应设备，不要发到公开聊天或网上。

## 1. 安装

1. 在连接键盘和鼠标的 Windows 电脑上运行多设备测试安装包，按提示选择安装目录。完成后可直接打开年年互联；若需要桌面图标，保留创建快捷方式的勾选。
2. 要连接另一台 Windows，在另一台电脑上运行同一个安装包并打开年年互联，选择「被控 Windows」。
3. 要连接 Mac，在 Windows 主控中点「导出 Mac 测试包」，通过微信等私密方式发到 Mac。Mac 解压后，按包内「安装说明」安装 Deskflow，并打开文件夹中的测试 App。请先核对已安装的 Deskflow，避免覆盖现有配置。
4. Mac 端需要本人在系统设置为**当前这份**测试 App 允许「辅助功能」和「屏幕与系统音频录制」；如有本地网络或钥匙串请求，核对应用名称后按系统提示处理。系统要求重新打开时确认打开的是同一份 App。

Windows 测试安装包未签名，Mac 测试 App 尚未使用 Apple Developer ID 签名或公证；系统可能提示风险，具体以当前系统提示为准。测试版目前只提供 Apple 芯片 Mac 包。

## 2. 添加一台电脑

1. 在接键鼠的 Windows 选择「主控电脑」，检查局域网地址并点「准备主控」。
2. 在另一台 Windows 的「被控 Windows」，或在 Mac 测试端，点「生成身份卡」，将它私下发给 Windows 主控。身份卡有效期为 **10 分钟**；过期就重新生成。
3. Windows 主控进入「配对」，点「导入设备身份卡」。与另一台电脑核对**完整键鼠指纹**，一致后点「核对并生成配对文件」，保存并私下发回对应电脑。
4. 在另一台电脑导入收到的配对文件，核对主控显示的**完整控制通道指纹**，一致后确认主控。不要把不同电脑的配对文件混用。
5. 若主控尚未启动共享，在「设备」中点「启动共享」；另一台在「键鼠」中点「开始连接」。如果出现键鼠指纹核对，和主控上的完整指纹一致后再确认。连接完成后选择设备，打开互联小窗。

要添加更多电脑，在主控的「配对」页点「继续添加设备」，对每台重复第 2～5 步。身份卡与配对文件的保存位置以保存窗口中的选择为准。

## 3. 日常使用

- 在 Windows 设置的「本机名称」点「修改名称」，可以使用中文；在主控的「设备」页选中另一台电脑后，点「更多」→「修改名称」。这些是当前电脑上的显示名称，不修改安全身份，也不会自动同步到其他电脑。
- 主控选择已连接的设备切换键鼠；各电脑使用自己的屏幕。放大画面后点「开始操作」可以临时操作画面中的电脑，结束时点「归还键鼠」或使用界面提示的快捷键。
- 普通键鼠切换和预览操作**目前不会自动切换共用显示器的视频输入**。显示器接口页面仅用于测试设置，多设备自动切屏尚未启用。
- 文件传输前，先在接收端选择收件文件夹；Windows 可选择 D 盘。共享文件夹不是自动同步，使用者需要自行选择和开启。
- 两端开启剪贴板后可同步文字和链接；当前不自动同步图片和文件。请避免在同步开启时复制不愿共享的敏感文字。

## 当前测试范围

笔记本主控同时连接一台 Windows 台式机和一台 Mac 的基本键鼠、预览、文本、文件和小窗功能已做实机测试。四台远端同时连接、干净设备完整安装、长时间稳定性、共用显示器自动切屏和正式发布所需签名及许可仍待验收。独立测试使用自己的资料目录，不应覆盖日常工具箱或原版配对。
