# 年年互联功能详解（内部测试）

本页描述源码中的多设备测试候选，以及已有实测和待验收的范围。不同时间的实测使用过不同测试包；它们不能合并为当前源码或正式发行包的完整验收。实际按钮文字与状态可能随候选版本变化。

## 软件解决什么问题

在同一可信局域网中，Windows 主控可以管理其他 Windows 或 Apple 芯片 Mac，按授权使用键鼠共享、画面预览、文字和文件协作。两台设备能在局域网相互通信时，互联网是否可用是另一回事；如果设备间的局域网连接断开，现有连接也会受到影响，自动恢复仍待完成和验收。

## 功能与当前状态

| 功能 | 可以做什么 | 已知范围 |
| --- | --- | --- |
| 局域网发现 | 被控设备选定活动网络并主动开放 30 秒，主控扫描设备。 | Windows 双机和 Windows–Mac 在历史候选各有一次发现/配对实测；新版及网络变化仍待验收。 |
| 免文件安全配对 | 在两端确认配对请求、核对完整指纹，不需要传递 JSON 配对文件。 | 两种设备组合各完成一次实测；拒绝、中断和恢复场景尚未全部验证。 |
| 键鼠共享 | Windows 主控选择已连接的设备，切换键鼠操作；使用界面或快捷键归还。 | Windows 双机和 Windows–Mac 各完成过一次切换与归还；仅键鼠应急归还、浮窗竞态及失联恢复仍未完成。 |
| 双向画面 | 分别选择“查看对方画面”和“允许对方查看我的画面”；放大预览可进入操作。 | Mac 曾完成一次画面预览操作与归还；最新候选及权限变化仍需实机复验。 |
| 文字剪贴板 | 两端按设置启用后同步文字或链接。 | 同步受开关控制；**图片或截图的剪贴板互传尚不支持**，图片文件可通过普通文件传输，仍需在对应候选上验证；未确认提供单独截图保存功能。 |
| 文件协作 | 选择并发送文件、设置接收文件夹，也可在已授权范围内访问主控共享文件夹。 | 曾使用历史候选实测文字、定向文件和主控共享文件夹；完整失败处理、反向共享及最新候选仍待验。 |
| 多设备管理 | 管理设备卡片、连接状态与本地显示名称。 | 候选配置最多四台被控；四台同时在线与最新版本的完整回归尚未验收。 |
| 显示器联动 | 展示显示器相关设置。 | 共用显示器自动切换输入尚未完成，不能将普通键鼠切换视为自动切屏。 |

## 使用前准备

- 两台设备连接同一可信局域网，主控电脑使用 Windows。被控设备可为 Windows 或 Apple 芯片 Mac；Mac 测试候选目前要求 macOS 14 或更新版本、Python 3 和 Deskflow。
- 使用独立测试版及独立资料。之前的正式版、历史配对和收到的文件应保留；若其他键鼠共享程序仍在运行，先正常退出相冲突的测试进程。
- Mac 按实际系统提示检查辅助功能、本地网络与屏幕录制权限。需要让对方查看 Mac 画面时，必须由用户本人授予对应录屏权限；具体提示以系统和实际进程为准。Mac 测试包尚未公证。
- 本仓库目前不提供已完整验收的通用安装包。构建入口和限制见[构建与测试状态](BUILDING.md)，实际操作见[多设备版使用说明](多设备版使用说明-内部测试.md)。

## 从发现到连接

1. 在 Windows 主控选择当前联网地址并准备主控；在被控 Windows 选择“被控 Windows”，或打开 Mac 测试窗口。
2. 被控设备刷新网络、选择当前活动局域网，点击“允许被发现 30 秒”并确认。开放期间，同局域网内设备可能看到本机名称、系统和键鼠指纹。
3. 主控扫描并向自己的设备发起安全配对，被控端确认是本人发起的请求。名称和扫描结果本身不能证明设备身份。
4. 两边分别核对两项**完整指纹**：主控显示的对方键鼠指纹对应被控本机键鼠指纹；主控本机控制通道指纹对应被控显示的主控控制通道指纹。两项均一致后，两端再确认；不一致或不能核对时取消。
5. 等待配对完成，然后按主控提示启动共享，并在被控端点击“开始连接”。如有首次键鼠指纹提示，应与主控的完整指纹核对一致后再确认。

较旧测试候选也可能使用身份卡和配对文件。配对文件包含控制凭证，应仅通过可信方式交给对应设备，不要提交到仓库或公开发送。

## 画面、键鼠和文件

- **查看与分享分别授权**：“查看对方画面”控制本机查看；“允许对方看我的画面”控制本机分享。Mac 多设备连接重新启动后，需要重新允许分享 Mac 画面。
- **操作与归还**：在 Windows 设备页选择设备并切换，或进入放大预览后使用“开始操作”。操作结束后使用停止/归还入口；历史测试也使用过 `Ctrl+Alt+F11`。归还结果要以实际键鼠位置和提示为准；若状态未确认，先用各设备自身键鼠检查。
- **文字与文件**：先在两端按需要开启文字剪贴板；文件传输前选择收件文件夹。共享文件夹与普通文件传输是不同入口，访问范围以授权为准。

## 已知问题与后续工作

当前项目仍处于内部审查阶段。新版界面和最新候选仍需要真实 Windows/Mac 设备复验；断线自动恢复、键鼠专用应急归还、浮窗并发处理、休眠/断网、四台被控并发、干净设备安装、Mac 签名与公证均未完成或未验收。全新 Windows 运行器的托管编译已通过，但旧安全测试工程仍存在编译问题；原生全链只在本机隔离目录编译成功，完整发行依赖和许可还未闭合。详见[项目进度](开源准备计划.md)及[许可与发布状态](开源许可核对.md)。
