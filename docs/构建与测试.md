- Mac 托管部分使用 .NET 10 和 Avalonia；原生媒体组件需要 Mac、Swift/Xcode 工具链，键鼠端使用系统安装的 Deskflow。现有测试候选面向 Apple 芯片。

工程提供 `scripts/build-managed.py` 的托管代码开发入口。安装 Python 3 和适用的 .NET 10 SDK 后，可在独立源码目录中先查看将执行的命令：

```text
python scripts/build-managed.py --target windows --multi-device --dry-run
python3 scripts/build-managed.py --target mac --multi-device --dry-run
```

去掉 `--dry-run` 才会执行构建；这两个入口分别针对 Windows 和 Mac 的隔离多设备托管候选，并非完整安装包。使用前应阅读脚本与依赖要求，在独立目录、独立测试资料和适用系统上执行；不同平台支持的测试不相同。现有源码曾在隔离目录使用本机 SDK 和缓存进行托管编译，这不能证明干净电脑可完整重建软件。

本次私有审查副本：在独立副本中使用本机 SDK 和 NuGet 缓存，Windows DiscoveryPortable 及 Mac DiscoveryCandidate（osx-arm64 交叉编译）托管项目均以 0 警告、0 错误构建成功。这不是 Mac 原生运行、安装包或干净机器验证。源码收集器测试 31 项通过，1 项因符号链接环境限制跳过；CI 结构、发现项目和托管构建脚本的定向 Python 测试分别通过 5、3、7 项。
