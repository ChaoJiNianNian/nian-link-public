## 2026-11-15：重建测试类型可空警告

测试专用的重建 `SecurePairingPeer` 中，资源局部变量及父目录变量按生命周期标为可空；将原有网络检查的临时布尔值改为相同顺序的短路条件。原先的失败清理、所有权转移和异常内容保持不变，生产类型未改。重建前后用相同 ILSpy 11.2.0 与 .NET 10 参考程序集反编译该类型，输出文本逐字节一致；原始 IL 长度和分支偏移发生变化，不能称 IL 完全一致。

新增 3 项直接针对重建类型的合成测试：非真实网络来源被拒绝并消费请求；合成 handoff 第二次网络重验失败时，恰好释放一次；handoff 已撤销时短路而不再次重验并释放一次。修改前后均通过，测试中途拒绝于证书读取和 Socket 创建前；反射伪造的 live 标志只用于测试，不表示真实网卡已验证，也不覆盖所有成功或失败清理路径。

使用隔离源码副本、SDK 10.0.404 和已有 NuGet 缓存完整重建，**0 警告、0 错误**；旧实验全套 **512 通过、1 项真实网卡测试未开启而跳过**。原始历史源码仍有八份未找回，该结果不代表当前生产端到端安全或完整干净环境构建已完成。

## 2026-11-15：源码漂移复审与安全测试

三处报警分别审查了当前生产文件、历史测试变体和现有生产测试。原始守卫的作用是**生产源码变化时要求复审**，并不证明测试变体等同生产实现。审查后记录新的四项源码基线；守卫仍会拒绝后续内容变化，只将 CRLF 统一为 LF 以避免 Git 换行转换造成误报，其他字节变化仍触发失败。该转换也会忽略多行文字内的换行差异，不能作为原字节完整性证明。第四项 PendingFreeze 只调整了摘要计算方式。该守卫仅检查列出的四个生产文件，不自动检查其他 partial 或测试变体。已用隔离副本的内容修改验证守卫实际失败，再恢复原文件。

- **Vault 基类：**当前生产使用 v3 数据格式和更大的历史数据上限，会拒绝使用历史或退休凭据，撤销时更新相应事务状态。旧测试变体已针对上述差异迁移，保留实验专用钩子与关闭等待；新增大历史数据重开、撤销状态和凭据碰撞回归。随机注入仅存在于测试变体，默认仍使用系统加密随机数。
- **主控 PendingGrant：**当前生产具备活动信任与磁盘一致性、容量及历史身份冲突检查；旧实验变体仍是独立历史协议，不能说两者等价。生产侧 `PairingHostCapacityTests` 覆盖损坏、容量和历史重放，本轮新增暂存中信任文件变化的定向回归，验证拒绝发布并保留变更证据。临时移除生产的第二次检查会使该回归失败；复原后通过。
- **被控 Peer pending：**当前生产有退休历史、会话租约与回执绑定、容量、READY/晋升保护和发布前预留复核；旧实验变体仍使用自身的测试协议。生产侧已有容量、退休、TLS 准备及跨会话租约检查，本轮新增删除或修改预留的两组回归，检查拒绝发布、旧邀请和篡改证据保持、合法原预留恢复后可暂存。临时移除生产的发布前复核时两组回归均失败，复原后通过。

此复审基于合成证书、回环连接和测试保护器；历史测试与实际生产测试分开运行。新的摘要表示本次已审查的输入，不表示两套状态机等价，也不证明真实 DPAPI、断电、多设备运行或发行验收。八份历史源码缺口仍在；当时重建测试类还有 13 个可空警告，后续处理见上节。未更改生产源码或现用软件。

以独立源码副本、SDK 10.0.404 和已有 NuGet 缓存运行：旧实验 **509 通过、1 跳过**（未启用真实网卡测试），当前生产 DeskLink **459 通过**，MultiPeerTrust **165 通过**。旧实验发现 510 项，按方法名及案例数量核对历史 501 项无缺失，新增 9 项；其中守卫的四项参数摘要已按上述复审更新。三套结果均为本机隔离验证，不是全新系统或 GitHub CI 结果。
