# 年年互联多设备 Windows 测试候选：使用说明

本候选仍处于内部验证阶段。它与现用正式版使用不同的资料目录；请保留正式版及原有配对资料。先停止其他键鼠共享程序，准备每台设备自己的键盘和鼠标。

## 启动和配对

1. 把测试包解压到独立文件夹，保持 App 和 Keyboard 的相对位置，然后双击 `Start-NianLink-Beta.cmd`。
2. 本候选需要 Windows 10 版本 2004 或更高、Microsoft Edge WebView2 Runtime，以及与 Windows x64 键鼠核心匹配的 Microsoft Visual C++ 运行库。缺失时应从微软官方网站获取。安装器仅检查 WebView2 与 VC++ 运行库注册信息是否存在，不证明版本、文件完整性或兼容性符合要求；目标设备上的干净安装和运行库版本仍待验证。
3. 主控和被控连接可信的同一局域网，分别选择对应角色。被控刷新并选择当前网络，开启限时发现；主控扫描后选择目标发起配对。
4. 双方逐字核对完整的设备键鼠指纹和主控控制通道指纹，一致后各自确认。若出现主控键鼠指纹提示，也要完整核对后再确认。
5. 被控点击“开始连接”。双方显示已连接后，在主控设备页选择目标并切换键鼠；通过界面的归还按钮或 Ctrl+Alt+F11 归还。

本候选为每个构建身份创建独立资料目录；同一构建重启可继续使用该测试资料，不同构建不会自动迁移配对，可能需要重新配对。请勿上传或公开包含配对凭证的资料。

## 已知限制

- 当前构建尚未完成真实双机、安装卸载、断线恢复和安全归还的完整验证。界面状态不明确或无法归还时，先使用本机键鼠停止操作并检查两端状态。
- Windows Runtime 和 WebView2 Runtime 的干净系统安装及载荷、第三方依赖和许可仍需核对。
- 本测试候选不包含 Mac 测试 App；Mac 需要另行准备对应版本及 Deskflow，并授予系统需要的权限。
- 历史版本的单次实测不代表当前包已完成验收。本说明不代表可以作为正式版或公开发行。
