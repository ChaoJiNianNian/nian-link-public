# 年年互联免文件配对：独立内测说明

这是仅供本人测试的候选版，自动发现与免文件配对尚待 Windows、Mac 真机完整验收，不能作为正式版使用。测试资料与现用正式版、旧发现测试版分开。不要把测试版当成正式产品分发。

多设备连接、画面和异常处理的整体流程另见[多设备版使用说明（内部测试）](多设备版使用说明-内部测试.md)。

## 启动和准备

1. Windows 笔记本在测试包中双击「笔记本-D盘启动.cmd」；Windows 台式机使用「台式机-H盘启动.cmd」。D 或 H 须为本机已就绪的固定卷；测试资料在所选盘的独立测试目录。两台电脑分别使用自己的目录。
2. Mac 使用单独提供的「年年互联·免文件测试」候选 App 和独立测试资料目录。系统权限针对当前这份 App 分别设置；按提示检查局域网、辅助功能和画面所需的录屏权限。启用新的测试 App 前，退出同名旧免文件候选，避免系统切回旧实例。
3. 让主控和被控接入同一个可信局域网。进行键鼠测试前暂停其他共享程序，避免争用。

## 清透蓝界面入口

- Windows 主控：在左侧「设置与权限」选择当前局域网地址并点「准备主控」，再到「发现与配对」扫描设备并发起免文件配对。
- Windows 被控：在「被控 Windows → 发现与配对」选择网络并主动开启发现；配对完成后在「设备」点「开始连接」。
- Mac 多设备测试版：在「发现与配对」选择网络并开启发现；配对完成后在「设备」开始连接。在「画面」中，“查看对方画面”和“允许对方看 Mac 画面”分别控制；每次重新启动本机多设备连接后，分享 Mac 画面需重新允许，系统录屏权限仍须按提示授予。
- Mac 测试 ZIP 为 Apple Silicon 内部候选，尚未签名或公证，且不自带 Deskflow；需通过项目隔离 staging 流程准备独立资料、临时签名及启动器，不能直接双击 ZIP 中的 App 当成正式安装版。

## 发现与免文件配对

1. 在键鼠所在的 Windows 选择「主控电脑」，选当前局域网地址并点「准备主控」。在另一台 Windows 选择「被控 Windows」，或打开 Mac 测试 App。
2. 被控端在「局域网发现（测试）」选当前网络，点「允许被发现 30 秒」并同意；发现期间局域网内可能看到设备名称、系统和指纹。主控点「扫描设备」，选中这台电脑，再点「免文件安全配对（测试）」。未发现时可检查两端网络，重新开启发现再扫描。
3. 被控端收到请求后，只有确认是自己正在操作的配对才继续核对。列表中的名称和请求内容尚未验证，不能仅凭名称确认身份。
4. 两边出现「核对本次安全连接」后，逐字核对：主控显示的对方键鼠指纹应与被控端的本机键鼠指纹完全一致；被控端显示的主控控制通道指纹应与主控显示的控制通道指纹完全一致。两边均一致后，各自在自己的电脑上确认；不一致或无法核对时取消。键鼠指纹与控制通道指纹是两项不同的核对。
5. 等待双方完成。主控提示设备已配对且共享已重启、被控提示配对已保存后，再在被控点「开始连接」。首次键鼠连接若提示核对键鼠指纹，仍需与主控完整指纹逐字核对后确认。配对完成和连接成功是两个不同状态。

上述免文件流程不需要手工传送身份卡或配对文件。当前界面可能仍显示文件配对入口，本次免文件测试请使用上面的按钮。

## 中断与恢复

- 显示「配对结果待确认」时，不代表成功或失败。两边点击「查看未完成的配对」，按界面提示处理；不要删除测试资料或重复发放配对文件来猜测结果。
- 如果界面允许恢复，让原来的被控设备重新开启发现，在主控重新发现并选中原设备，再次核对双方完整指纹并按提示恢复。恢复结果可能是完成，也可能是安全终止；以界面实际结果为准。
- 显示「安全终止」表示该次配对没有因此建立。显示已配对但共享重启未完成时，按界面提示手动重新启动共享。连接异常或恢复无法进行时保留现有状态和提示内容，停止测试并反馈。
- 取消、超时、断网或关闭窗口后，以双方界面的实际状态为准；发现到设备、双方开始核对或其中一方显示等待，均不等于配对已完成。

本候选仍需跨设备测试、断线与异常恢复验证；Mac 系统权限、键鼠连接和画面功能需按系统提示及实际情况逐项验证。测试过程不要覆盖或删除现用正式版及原有配对资料。
