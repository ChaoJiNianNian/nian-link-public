# 多设备版使用说明（内部测试）

本文介绍隔离测试候选的操作思路，不是正式安装指南。本仓库不提供已经完整验收的通用安装包；测试时请使用为对应设备准备的测试包及其说明，并保留现有应用和配对资料。

Windows 作为主控时，可以连接 Windows 或 Apple 芯片 Mac 被控。不同候选的页面名称可能不同，请以正在运行的测试版实际提示为准。Mac 测试包当前要求 macOS 14 或更高版本、系统 Python 3 和已安装的 Deskflow；尚未公证，其他 Mac 环境尚未验收。

## 连接前

1. 将两台设备连接至同一可信局域网。局域网可用但互联网断开，与两台设备之间断开连接是不同情况。
2. 使用独立测试资料，正常退出可能争用键鼠的旧测试进程或其他键鼠共享程序。不要删除现用程序或旧配对资料。
3. Mac 根据当前系统提示检查本次测试 App、实际使用的 Deskflow 及媒体采集进程所需的辅助功能、本地网络或屏幕录制权限；需要对方看到 Mac 画面时，屏幕录制权限需由用户本人授予。若系统要求重开，请重新打开同一份独立测试版。

## 自动发现与免文件配对

以下适用于具备免文件配对入口的多设备测试候选：

1. Windows 主控在设置中选择当前活动局域网并点击「准备主控」。另一台 Windows 选择「被控 Windows」，或打开 Mac 多设备测试窗口。
2. 被控设备刷新网络，选择当前联网地址，点击「允许被发现 30 秒」并同意。开放期间，同一局域网设备可能看到本机名称、系统和键鼠指纹。
3. 主控在「发现与配对」中扫描，选择自己的设备并发起「开始安全配对」。被控设备确认是本人正在进行的请求后，点击「继续核对」。发现结果和名称不等于可信身份。
4. 双方逐字对照两项完整指纹：主控显示的对方键鼠指纹与被控本机键鼠指纹；主控本机控制通道指纹与被控显示的主控控制通道指纹。**两项分别一致后**，双方再各自确认；不一致或无法核对时取消。
5. 等待双方完成。如果主控提示配对已完成但共享重启未完成，请先在主控「设备」页按提示启动共享。然后在被控端点击「开始连接」。首次键鼠连接如有指纹提示，先与主控显示的完整键鼠指纹核对一致，再确认。配对成功与连接成功是两个不同状态。

较旧的内测安装器使用身份卡和配对文件：被控端生成身份卡交给主控，主控核对设备指纹后生成配对文件，被控端私下导入并核对主控控制通道指纹。配对文件含控制凭证，只交给对应设备，不要公开发送或提交仓库。

## 查看画面、切换与归还

- 「查看对方画面」控制本机查看；「允许对方看我的画面」或 Mac 的「允许对方看 Mac 画面」控制本机分享。两个方向分别授权，Mac 多设备连接重新启动后需要重新允许分享。
- Windows 主控选择设备后可使用「切换到这台电脑」；归还时使用界面中的「归还主控」或界面提示的快捷键。以实际键鼠位置和状态为准，不要只凭一次文字提示判断安全。
- 放大预览中的「开始操作」属于单独入口；结束时使用窗口的停止或归还入口。多设备预览和普通切换不应被当作已经实现共用显示器自动切屏。
- 文件传输前应在接收端设置收件文件夹；文字剪贴板与文件传输分别控制。使用者应自行决定是否开启共享。

如果归还提示未确认、浮窗消失、键鼠不在预期设备或连接异常，停止反复切换，用各设备自身的键鼠检查当前焦点和连接状态，保留提示供排查。仅键鼠应急归还、浮窗并发处理及断线自动恢复尚未完成。

## 验证范围

此前使用不同隔离候选在 Windows 双机和 Windows–Mac 组合上分别做过一次免文件配对和键鼠切换归还；这些记录不能代替当前源码、最新候选、真实断网或长期稳定性测试。Mac 原生权限、干净设备安装、四台被控并发、签名与公证仍待验收。

## 常见问题

### 扫描不到设备

确认两台设备选择的是当前活动网络，且确实可以在同一可信局域网内通信；被控端刷新网络后重新选择地址，并在需要时再次开启 30 秒发现。发现窗口到期后需要重新授权。名称相似也不能代替指纹核对，网络结构、防火墙或设备隔离可能影响发现；不要关闭身份校验来绕过问题。

### 配对成功后没有连接

配对与启动键鼠连接是两个步骤。先检查主控共享状态，再在被控端点击“开始连接”；首次提示键鼠指纹时应与主控完整指纹核对一致。若系统提示已有 Deskflow 核心在运行，先识别它属于哪一份应用，正常退出与测试冲突的旧测试程序，不要随意关闭现用正式版的进程。

### Mac 连接失败或看不到画面

按实际提示检查测试 App 和实际被使用的进程所需的辅助功能、本地网络和屏幕录制权限；系统若要求退出重开，使用同一份独立测试版重新打开。查看对方与分享本机画面分别控制，查看方向及被查看方向都需要对应授权；Mac 多设备连接重启后应重新允许分享 Mac 画面。不要仅凭错误码推断唯一原因。

### 键鼠归还不确定

使用界面中的停止或归还操作；历史测试中 `Ctrl+Alt+F11` 曾成功归还。若提示未确认或键鼠焦点仍不在预期设备，使用各设备自身的键鼠检查状态，避免反复切换，并保留错误提示供排查。自动断线恢复和仅键鼠应急归还仍未完成验收。

### 图片和截图怎么传

当前剪贴板同步为文字和链接，**图片或截图的剪贴板互传尚不支持**。已经保存为文件的图片可使用普通文件传输入口，实际行为仍需在所用测试候选验证；不要把画面预览理解为已经提供截图保存功能。
