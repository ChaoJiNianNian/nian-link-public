# 年年互联多设备版使用说明（内部测试）

本文介绍清透蓝多设备**独立内测候选**的基本流程，供项目审查与测试使用。它不是正式版安装教程，也不表示当前源码已经打包或通过完整验收。现用桌面工具箱中的年年互联是另一版本，请继续保留原程序和原配对资料。

本文对应 Windows 免文件便携测试包与单独准备的 Mac 清透蓝测试启动包；不同候选的页面名称和步骤可能略有差异，以所用包内说明和实际窗口为准。Windows 测试包包含为测试机器准备的独立启动脚本和资料目录；Mac 测试启动包需按包内说明在独立目录准备，**不要覆盖已有 App 或 Deskflow 配置**。这些不是通用安装器或公开下载包。

目前 Mac 测试包针对 Apple Silicon，要求 macOS 14 或更高版本、系统 Python 3 和已安装的 Deskflow；Mac App 尚未公证。Intel Mac、其他系统版本和干净设备安装尚未验收。两种设备组合曾各完成一次免文件配对与键鼠切换实测；这些结果来自不同候选，不能代替清透蓝新包、最新源码或异常场景验收。

## 连接前准备

1. 将一台 Windows 电脑作为主控，另一台 Windows 或 Mac 作为被控设备。两台设备应连接同一个可信局域网；只断开互联网但局域网仍可用，与设备间局域网断开是两种不同情况。
2. 使用各自测试包提供的启动入口和独立测试资料；先正常退出可能争用键鼠的旧测试程序或其他键鼠共享软件。不要删除或覆盖现用版和真实配对。
3. Mac 按实际提示检查局域网、辅助功能及屏幕录制权限。辅助功能可能涉及本次测试 App 和实际运行的 Deskflow；屏幕采集使用 `DeskLinkMedia` 组件，系统可能显示 App 或实际媒体进程名称。请以系统列出的本次程序及实际提示为准检查相应权限，不要假定只打开某一个 App 开关就足够。若系统要求重开，重新打开同一份独立测试版。

## 首次发现与免文件配对

1. 在 Windows 主控选择「主控电脑」，到「设置与权限」选择当前使用的局域网地址，点击「准备主控」。在另一台 Windows 选择「被控 Windows」，或打开 Mac 多设备测试窗口。
2. 在被控设备的「发现与配对」中点击「刷新网络」，选择当前联网的地址，点击「允许被发现 30 秒」并同意。发现开放期间，同一局域网的其他设备可能看到本机名称、系统和键鼠指纹。
3. 主控进入「发现与配对」，点击「扫描设备」，选中自己的设备并发起「开始安全配对」。被控端收到请求后，确认是本人正在操作的请求，再点「继续核对」。发现到设备或收到请求并不代表身份已经验证。
4. 两台电脑显示「核对本次安全连接」后，逐字对照两项**完整**指纹：
   - 主控显示的对方设备键鼠指纹，与被控设备显示的本机键鼠指纹。
   - 主控显示的本机控制通道指纹，与被控设备显示的主控控制通道指纹。

   两项分别完全一致后，双方各自点击「一致，确认」；不一致或无法核对时取消。不要仅凭设备名称确认身份，也不要公开发送配对凭证。
5. 等待双方提示配对完成。如主控提示“设备已配对，但共享重启未完成”，先到主控「设备」页按提示点击「启动共享」。然后在被控端的「设备」中点击「开始连接」；若首次连接要求核对主控键鼠指纹，先与主控「设备 → 连接详情」中的完整主控键鼠指纹对照，一致后再确认。**配对完成和已连接是不同状态**，请以两边实际显示为准。

上述流程不需要手动传输配对文件。较旧的多设备安装版可能使用身份卡和配对文件，相关备用流程见[安装与首次连接（旧内测安装器）](USER-GUIDE.md)；配对文件含控制凭证，只能私下交给对应设备。

## 查看画面与键鼠

画面权限是两个独立方向：**查看对方画面**决定本机是否查看，**允许对方看我的画面**决定是否分享本机画面；Mac 对应名称是「允许对方看 Mac 画面」。只打开一边不会自动打开反方向。

- 例如让 Windows 看 Mac：在 Mac「画面」开启「允许对方看 Mac 画面」，在 Windows 选中 Mac，进入「画面」并开启「查看对方画面」。Mac 多设备连接重新启动后，分享 Mac 画面需要再次由用户允许；还需满足系统录屏权限。
- 例如让 Mac 看 Windows：在 Windows 开启「允许对方看我的画面」，在 Mac 开启「查看对方画面」。不需要分享时可分别关闭相应开关。
- 普通键鼠切换：在 Windows 主控「设备」中选中被控设备，点击「切换到这台电脑」。需要归还时使用界面中的「归还主控」或 `Ctrl+Alt+F11`；归还结果以界面和实际键鼠位置为准。
- 预览操作：在「画面」中打开「放大预览」，在预览窗口点击「开始操作」；结束时使用窗口里的停止或归还入口。预览操作与普通切换是不同入口，不应假定它会自动切换共用显示器输入。

## 异常时怎么处理

- 搜不到设备：确认双方在同一局域网、被控端选对活动网络并重新开启发现，再由主控扫描。显示名称相同不等于设备身份相同。
- 提示「配对结果待确认」：不要把它当成成功或失败，也不要删除测试资料；在两端查看「未完成的配对」并按实际提示处理。
- 开始连接时提示已有 Deskflow 核心运行：先检查并正常关闭旧测试窗口或其他共享程序。不要结束不认识的进程，也不要修改现用正式版。
- 看不到画面：确认发送画面的一方已允许分享、查看的一方已开启查看，并根据系统实际显示检查本次 Mac 测试 App 或媒体采集进程的屏幕录制权限。
- 归还提示未确认、浮窗消失或键鼠不在预期设备时：不要假定已经归还，也不要反复发起切换；先用各设备自己的键鼠检查当前焦点和连接状态，保留页面提示以便排查。该候选的应急归还与浮窗并发问题仍未完成修复。
