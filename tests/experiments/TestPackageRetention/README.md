# 测试包两代保留：合成模型

本目录是独立实验，不接入 Windows 或 Mac 打包入口，不处理现有测试包、正式安装或任何 profile。PowerShell 模型只接受当前进程临时目录下指定前缀的空夹具目录；`GetTempPath` 受进程环境变量影响，这个路径约定并非安全沙箱。合成包仅为单个小文件，不代表真实测试包及其最终校验。

模型针对两种合成类型分别维护当前、上一和待验证身份。单次验证成功后才更新索引；两代已满或存在待验证身份时拒绝创建新目录。索引记录合成文件摘要，再次读取时核对已记录内容；遇到越界、重解析点、未知输出、残留索引暂存文件或占用锁即拒绝。它以合成夹具根目录为键使用现有项目构建锁，并非锁住实际项目；该锁仅对接入者且在当前会话内生效，不防止其他进程修改文件。路径检查与文件操作之间仍存在外部进程替换路径的竞态。

运行：

```powershell
python -B tests/experiments/TestPackageRetention/test_retention_fixture.py -q
```

测试只使用新建合成临时目录。测试通过人为放置索引暂存文件模拟中断，没有实际强制终止进程或断电。预留写入与创建目录之间若发生中断，模型会停止且尚未实现自动恢复或清理。摘要和索引由同一用户控制，只能检查单边变化，不能证明来源或防止同时篡改两者。未覆盖真实包格式、打包入口的最终策略验证、所有跨进程攻击、掉电持久性或真实发布。容量满后模型不会覆盖、移动或删除任何旧数据，因此也不能自动腾出空间。
