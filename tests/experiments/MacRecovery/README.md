# Mac 协作恢复与预览会话研究

这里是独立实验和测试材料，不属于当前发行软件，也不接入现用程序。测试使用合成身份、临时目录和本机回环连接，不连接真实设备。`MacMultiPreviewControl.cs` 是未接线的实验快照，不代表完整安全实现；不要把实验成功当作自动恢复已经完成。

需要 .NET 10 SDK 和相应的 NuGet 测试依赖。从仓库根目录执行：

```powershell
dotnet test tests/experiments/MacRecovery/MacRecovery.Experimental.Tests.csproj -c Release --filter "FullyQualifiedName~RealSessionMustNotTreatViewingAsReturnProofAfterTimedOutTls|FullyQualifiedName~MacOwnerMustBlockNewControlAfterTimedOutBegin"
```

上述命令曾在 Windows 隔离副本中使用本机 SDK 和 NuGet 缓存运行，七项通过。这只覆盖同进程、合成回环 TLS 和所有者状态，不是 Mac 原生运行或真实设备验收。实验路径默认使用系统临时目录，生成独立随机子目录，并在操作前拒绝包含链接的路径。

完整研究测试包含此前用于复现未修复问题的预期失败案例，不能将其当作正式回归门禁。`UI归还入口候选测试.txt` 是研究片段而非可执行测试。跨进程恢复、真实断网和应急归还等仍需另行设计并验证。

## 保留的历史反例与验证详情

以下是此前各独立实验的记录，数字不能合并为产品验收：

第一条目前 **1 项失败**：真实客户端通过 TLS 发出 Begin，合成服务收到请求后丢失响应并延后处理；后续独立 Read 先返回 `Viewing`，而旧 Begin 仍可随后生效。实验包装器错误地把一次 Read 当成排空证明。测试结束时反射释放登记仅用于隔离环境清理，不是产品允许的归还证明。

第二条目前 **2 项失败**：断开对端后，Mac 的画面分享状态仍开启；重启对端后，手动刷新仍可使原协作状态重新上线。这个实验调用当前未接线的原有 getter 服务路径，不能证明自动恢复或故障停用已经完成。

第三条目前 **3 项通过**：直接构造真实共享预览会话和真实 TLS 客户端，先复现 Begin 超时后首次清理读取或定时读取，以及 End 超时后定时读取导致的错误重入，三项均曾失败；修复后，合成服务仍可在后续 `Viewing` 读取后执行迟到动作，但当前会话保持未确认并拒绝重入。测试不含真实 UI 或键鼠动作，只验证当前会话，关闭窗口、重开、其他会话及普通切换仍需所有者级保护；不代表远端动作停止或真实设备安全归还已经确认。

第四条目前 **4 项通过**：真实 `MacMultiPeerClient` 使用临时身份、模拟核心进程和状态 IPC，首次预览 Begin 已到达本机 TLS 合成服务但响应超时，当前 session 显示未确认。原先关闭该 session 后新 session、普通切换以及同一 owner 停止再开始连接，三项均可发送新动作且测试先失败；接入同 owner 保护后不再发出新动作，并验证重启后旧代理遭拒。新增应急归还仍尝试发送但不能清除未知状态的测试通过。每种场景仍释放第一条请求并观察合成动作迟到生效；测试只覆盖同一个 owner、本机合成对端及内存状态，不证明原生 Mac、跨进程或跨主控安全归还，亦不能认为旧请求已停止。研究工程不属于默认测试。
